🎯 COMMON ISSUES AND SOLUTIONS
═══════════════════════════════════════════════════════════════════════════

Issue 1: "Permission denied" when fixing permissions
─────────────────────────────────────────────────────
Solution:
  Contact hosting provider - you may need elevated privileges
  Or try: sudo chmod -R 775 storage bootstrap/cache

Issue 2: "php: command not found"
─────────────────────────────────────────────────────
Solution:
  Try: php81 artisan config:clear
  Or: /usr/bin/php artisan config:clear
  Or: which php (to find PHP path)

Issue 3: Still getting 403 Forbidden
─────────────────────────────────────────────────────
Solutions:
  1. Check demo mode (Step 5 above)
  2. Check ModSecurity logs with hosting provider
  3. Verify .htaccess file in public/ directory
  4. Check web server error logs
  5. Ensure database connection is working

Issue 4: "Storage link already exists"
─────────────────────────────────────────────────────
Solution:
  This is normal - link already created
  Verify: ls -la public/storage
  Should show: public/storage -> ../storage/app/public

Issue 5: SSH connection refused
─────────────────────────────────────────────────────
Solution:
  1. Verify server details are correct
  2. Check if SSH is blocked by firewall
  3. Try from different network
  4. Contact hosting provider

═══════════════════════════════════════════════════════════════════════════
🔒 SECURITY NOTES
═══════════════════════════════════════════════════════════════════════════

1. Password Security
   - Server password is not stored in any script
   - Always enter password manually when prompted
   - Never commit passwords to version control

2. File Permissions
   - 775 allows owner and group read/write/execute
   - This is required for web server to write files
   - More restrictive than 777 (which allows everyone)

3. Production Settings
   - Always set APP_DEBUG=false in production
   - Set APP_ENV=production
   - Keep .env file secure (never commit to git)

4. Demo Mode
   - When enabled, prevents all data modifications
   - Useful for demo sites
   - Must be disabled for real production use
